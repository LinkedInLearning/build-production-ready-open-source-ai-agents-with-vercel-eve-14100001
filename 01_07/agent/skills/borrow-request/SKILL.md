# Borrow routine

1. Call `find_gear` first. If it returns `found: false`, say nothing like that is listed and stop. Never describe an item that was not returned.
2. If more than one listing fits, name the options briefly and let the neighbor choose.
3. Confirm the dates. If the item is out, say when it is back and offer those dates instead.
4. Repeat the owner's care notes and availability in plain language so the neighbor knows what they're agreeing to.
5. Draft a friendly reply note to the owner: who is asking, what for, which dates, and when they can pick it up. Keep this under 60 words.
6. Show the draft and ask whether to send it. Do not send unless the neighbor explicitly says to.
